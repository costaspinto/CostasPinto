# Portfolio update (2026-10-12)

## Included
- Feedback form is a dedicated `/feedback` page; the homepage has a discreet header link beside the navigation rather than a large feedback call-to-action in the recommendations section.
- Admin → Site appearance has four palette presets, eight editable color tokens, instant preview of navigation/hero/cards/secondary section patterns, and reset-to-saved/save controls.
- Appearance is stored in the existing `site_settings` JSONB setting and passed to the global layout as CSS variables. Shared public-section styling consumes these variables so backgrounds, cards, headings, text, borders, links and buttons update as a system.
- Admin recommendation moderation supports approve/publish, unpublish/unapprove and reject/hide.
- Admin has shortcuts for appearance, visitor analytics and recommendations. Analytics shows 7-day event count, 30-day event count, estimated unique visitors and recent events.

## Supabase setup
If appearance saving reports database setup required, run `supabase/migrations/20261012000600_site_appearance.sql` in Supabase SQL Editor after checking existing migration history. Analytics requires the included analytics migration(s), including `supabase/migrations/20261012000500_visitor_analytics.sql` and any prerequisite migration that creates `analytics_events`.
