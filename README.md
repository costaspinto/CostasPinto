# Costas Pinto Portfolio

A full-stack, AI-powered personal portfolio designed to showcase my technical expertise, projects, professional experience, education, and certifications through a dynamic and secure platform.

Built with **Next.js 15, React 19, TypeScript, and Supabase**, the platform integrates GitHub repository synchronization, LinkedIn authentication, and an AI-powered chatbot for an interactive professional experience.

### Core Capabilities

- **Dynamic Portfolio:** Manage and publish projects, skills, certifications, education, and professional experience.
- **Admin Dashboard:** Secure authentication and centralized content management.
- **GitHub Integration:** Automatically discover and import public repositories.
- **LinkedIn Integration:** OpenID Connect authentication and profile claim synchronization.
- **AI Assistant:** Context-aware chatbot powered by OpenRouter.
- **Security:** Server-side authorization, protected API routes, and controlled database access.
